## 본 뒤 문제 없다고 뺀 것

- **축제 가판대 재구매(C3 ⑦)로 가구 복제**: `OWNED`일 때 다시 넘겨주는 길은 가구 `claim`이 창고에 없을 때만 넣는다. `furniture:<계정>` 목록에서 가구를 빼는 코드가 서버 어디에도 없어서(판매·선물로 빠지지 않음) 다시 받을 수 없다. 칭호는 `eventTitleGive`가 이미 있으면 `null` → 오류로 돌아간다. 문제 없음.
- **부탁 받기/그만두기(v168)로 포인트 두 번 받기**: 심부름 보상은 `claimEvent`(심부름 ID당 한 번), 이야기 단계 보상은 `payKey`(주·이야기·단계당 한 번)라서 그만뒀다가 다시 받아도 두 번 받지 못한다. 「할게요」에는 보상이 없고, 그날 처음 말 건 호감도 +1도 하루 한 번 그대로다. `accept`·`decline`은 주민을 내가 붙잡고 있을 때(`hold`)만 된다. 새 API `/api/island/errand/drop`·`/api/island/quest/drop`은 로그인한 본인 계정 것만 바꾼다.
- **이야기 offer 흐름**: 받기 전에는 `questApply`가 `null`(저장 없음)이고, 두 번째 `talk`이 다시 offer를 만든다. 「그만둘래요」는 `taken:false, count:0`로 단계를 유지하고, 이미 받은 보상은 그대로다.
- **대회 정산 순서(C3 ③④⑧)**: 결과 표시를 맨 나중에 하므로, 중간에 실패하면 다음 분에 다시 돈다. 1~3등 포인트(`econtest_<날짜>` 청구)·칭호·트로피(`claim`)는 모두 한 번만 주므로 다시 돌아도 두 번 받지 않는다. 매분 정산이 겹쳐 돌아도 같다. `eventRoundClose`는 저장한 뒤에 지우므로, 저장에 실패하면 그 판이 남아 다시 시도한다.
- **요리 재료 돌려주기(C3 ①)**: 물고기는 쌓이는 물건이라 `meta`가 없다. 돌려줄 때 `meta: null`이어도 잃는 정보가 없다. 돌려주는 `quiet:true`는 생활 활동 보너스를 안 준다.
- **미션 capped(C3 ⑤)**, **메신저 바쁜 방(C3 ②)** 합치기: 중복 줄이나 빠지는 줄이 없다.
- **XSS**: 범위 안에서 새로 생긴 `innerHTML`·`insertAdjacentHTML`이 없다. 이름표(`setPlayerCard`), 판 위 쪽지(`boardNote`), 부탁 쪽지, 완료 카드, 할 일 카드는 모두 `textContent`를 쓴다.
- **이름표 옮기기(v173 `placeMySeat`)**: `renderTeamPlayers`(`app.js:8067`)가 `setRoomPlaying`(`:8185`)보다 먼저 돌아서, 판이 진행 중일 때 팀 카드를 다시 만들어도 옛 카드는 지워지고 새 카드만 내 자리로 간다. 흑·백 카드는 판이 끝나면 원래 자리(VS 앞뒤)로 돌아간다.
- **판 번호 키**: 「한 판 더」 키에 쓰는 `state.game.round`는 결과 카드를 쓰는 게임(오목·2vs2·오델로·사목·점과 상자·윷·부루마블) 모두 서버의 `reset`이 판마다 올려 준다. 그래서 다음 판 결과에서 미리 잠기는 일은 없다(P2-1은 실패할 때만 생김).
- **채팅 창 옮기기(v170)**: 머리와 모서리에 `touch-action:none`이 있어서 휴대폰에서도 끌린다. 리스너는 손을 뗄 때(`pointerup`·`pointercancel`) 지워진다. localStorage 값이 깨져 있으면 숫자 검사로 버린다.
- **낚시 화살표(v167)**: 화살표가 떠 있는 동안만 `islandFishing`으로 조이스틱과 버튼을 숨기고, 끝나면(`fishArrowsEnd`) 되돌린다.
- **주민 길찾기(v169 `pathTo`)**: 길이 없으면 바로 순간이동하고 `route:null`로 둔다. `routeTarget`은 `route`가 있을 때만 불린다.
- **고스톱 서버 규칙**: 이 범위에서는 서버 쪽에 테스트용 `wide-floor` 판만 더해졌다(`NODE_ENV==='test'`에서만). 판 진행, 결과 계산, 3인 판, 재접속 코드는 바뀌지 않았다.
