# Claude Code prompt-audit와 CLAUDE.md 정리 기준

출처: https://www.gymcoding.co/articles/claude-code-prompt-audit-claude-md-guide (2026-10-10 확인 후 요약)

## 핵심

- `/doctor prompt-audit [경로]`(별칭 `/checkup`, v2.1.283 이상)는 CLAUDE.md·AGENTS.md·스킬·명령·에이전트 파일에서 낡았거나 충돌하는 지시를 찾아 리포트와 수정 diff를 제안한다. 경로를 생략하면 전체가 대상이므로 처음엔 파일 하나만 지정한다.
- 기존 진입점 `/claude-api prompt-audit`(v2.1.221 이상)도 계속 쓸 수 있다.
- 강조("반드시", "절대")나 횟수("두 번 확인")를 반복하기보다 **어떤 조건이 충족되면 완료인지**를 적는다. 최신 모델은 낡은 재확인 지시를 문자 그대로 따라 불필요한 추론·도구 호출을 한다.
- 글에 인용된 실험: 비용 약 9% 추가 감소, 정확도 약 2%p 상승. 특정 벤치마크의 평균이며 다른 파일에서도 같은 결과가 나온다는 보장은 없다.

## 지시별 판단 기준

| 판단 | 기준 | 예 |
|---|---|---|
| 유지 | 팀만 아는 제약, 실제 사고를 막는 조건 | 주문 취소 시 재고 복구는 한 번만 |
| 구체화 | 취지는 맞지만 모호함 | "잘 테스트해" → 테스트 명령과 통과 기준 |
| 최신화 | 현재와 다른 경로·명령 | 없어진 스크립트 교체 |
| 삭제 후보 | 없어도 되고 중복 행동만 만듦 | 모든 답변 전 같은 자료 재검색 |

- 이유가 안 적혀 있다는 것만으로 지우지 않는다. 삭제·배포·인증·결제 규칙은 코드나 담당자로 확인한다.
- 반복돼 보여도 상황이 다르면 합치지 않는다.

## 점검 절차

1. `claude --version`으로 v2.1.283 이상인지 확인하고, CLAUDE.md를 백업하거나 기존 변경을 정리한다.
2. 파일 하나로 `/doctor prompt-audit CLAUDE.md`를 실행하고, 먼저 리포트와 제안 diff만 달라고 요청한다.
3. 리포트의 High/Medium/Low는 삭제 안전도가 아니라 **근거 수준**이다. Low와 `flag` 항목은 적용에서 제외된다.
   - High: 공식 문서·모델 오류·저장소의 명확한 모순
   - Medium: 일관되게 관찰된 동작
   - Low: 표현·관행에 기반한 추정
4. 번호를 지정해 일부만 적용하고 최종 diff를 확인한다. 안전 규칙(운영 DB 제한, 검증 실패 보고)이 남았는지 본다.
5. 수정 전후 같은 모델·설정·시작 상태의 새 세션에서 같은 과제를 맡겨 성공 여부를 먼저, 그다음 시간·도구 호출 수·사용량을 비교한다. 중요한 변경은 여러 번 확인한다.

## 수정 패턴 예시

- 검증 강화: "두 번 확인" → "금액 계산을 바꾸면 쿠폰·배송비·반올림 테스트를 실행하고, 실패하거나 미실행이면 완료로 보고하지 않음"
- 수정 금지 보강: "건드리지 마" → 대상 경로, 이유, 올바른 변경 절차(원본 수정 후 생성 명령) 추가
- 과도한 절차 축소: 전체 읽기·전체 테스트 2회 → 영향 범위별로 구분. 백업→마이그레이션→검증 같은 순서 절차는 유지
- 충돌하는 완료 기준: "실패 시 완료 금지"와 "짧게 보고"가 충돌하면 통과·실패·미실행을 구분해 보고하도록 합의

## CLAUDE.md에 넣을 것

- 프로젝트 배경과 핵심 규칙
- 실제 존재하는 빌드·테스트·생성 명령
- 작업 유형별 검증 방법
- 수정 금지 경로와 올바른 수정 절차
- 운영 제약
- 결과 보고 형식 (통과/실패/미실행 구분)

## 정리 대상

- 근거 없는 강조어 반복
- 확인 가능한 조건으로 바뀌지 않은 모호한 지시("꼼꼼히", "여러 번")
- 없어진 명령·경로
- 같은 상황의 중복 문장
- 사소한 작업에도 적용되는 전체 점검 절차

## 기타

- 길이 제한은 글에 명시되지 않았다. 기준은 길이가 아니라 필요한 조건이 빠짐없고 불필요한 절차가 없는가다.
- 운영 DB 보호는 지시 파일에만 맡기지 말고 실제 접근 권한과 도구 권한 설정으로 별도 제한한다.
- 검토만 원하면 "파일은 수정하지 말고 리포트와 diff만"이라고 요청한다. 이는 스킬 지침이지 권한 차단이 아니다.
- 스킬은 고정 검사기가 아니라 버전·환경에 따라 결과가 다를 수 있다.

## 이 저장소 적용 메모

- [CLAUDE.md](../CLAUDE.md)의 "작업 규모에 맞는 모델 추천을 한 줄로 적는다"처럼 완료 조건이 없는 항목이 점검 대상 후보다.
- 실행 시 `/doctor prompt-audit CLAUDE.md`를 리포트 전용으로 돌린 뒤, 근거를 이해한 항목만 적용한다.
