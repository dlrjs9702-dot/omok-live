# 작업 지시·작업 카드 양식 (4항목)

Claude Code에 맡기는 코드 작업과 Codex에 맡기는 에셋 주문(AGENTS.md §8)에 같은 양식을 쓴다. 한 장에 4항목만 적는다. 비공개 기록 본문은 옮기지 않고 링크만 둔다.

에셋 주문은 「배경」에 에셋 ID·크기·필요한 동작 이름·예산(삼각형·재질, `tools/assets/budgets.json`)을, 「결과」에 `바탕화면\아일랜드\assets\<주문 이름>` 폴더와 산출물 목록을 적는다. 코드는 에셋이 오기 전에 임시 모양으로 먼저 완성하고, 에셋이 오면 같은 ID로 교체한다.

**3D 에셋 주문에는 「Blender 다듬기」 단계를 꼭 넣는다(사용자 지시 2026-10-13).** 스크립트로 만든 모양을 작업 PC의 Blender(5.2 LTS, `C:Program FilesBlender FoundationBlender 5.2`)를 화면 없이(`blender -b -P <스크립트>`) 한 번 더 거쳐 각진 느낌을 줄인다 — 모서리 둥글게 깎기(bevel), 미세 요철, 정점색 그늘(AO) 굽기, 그 뒤 삼각형 예산·정점색만·압축(KHR_mesh_quantization + EXT_meshopt_compression)·원점·크기 규격을 다시 맞춘다. 다듬기 스크립트와 다듬기 전/후 비교 미리보기를 산출물에 함께 넣고, README에 Blender 버전과 다듬기 여부를 적는다. 1m 단위로 이어 붙는 조각(길 판석 등)은 이음 끝 치수가 바뀌지 않게 하고, 효과가 없는 아주 작은 부품은 이유를 적고 건너뛸 수 있다. 2D(SVG) 주문에는 해당 없음.

## 양식

```
결과: 끝났을 때 손에 쥘 것 한 가지 (예: 낮/밤이 서버 시계로 같이 바뀐다)
배경: 누구를 위한 일이며 지금 어떤 상태인가 (코드 위치·관련 기록 링크)
제약: 먼저 물어봐야 하는 일 (버전/공지 변경, 배포, 데이터 삭제, 범위 밖 파일)
질문 기준: 꼭 필요할 때만 묻는다 / 그 외에는 기존 패턴대로 진행하고 끝나면 요약 보고
(3D 에셋이면 「제약」 또는 「배경」에 한 줄: Blender 다듬기 단계 포함 — 위 규칙)
```

## 종류 표시 (사용량이 끊길 때 이어받기 위한 한 줄)

- 종류: 코드 | 에셋 | 문서
- 크기: 작음(30분 안) | 보통 | 큼(쪼갤 것)
- 확인 방법: 이 작업이 끝났다고 말할 수 있는 검사 한 가지

## 예시

```
결과: 섬의 낮·밤이 서버 시각 기준으로 모든 접속자에게 같은 시각으로 보인다
배경: 지금은 브라우저마다 시각 계산이 따로다. public/plaza/island.js, server.js의 now 값
제약: 버전·공지 변경과 배포는 묶음 끝에 한 번. 기존 이동·동기화 테스트는 유지
질문 기준: 시간 길이(하루 몇 분) 같은 수치만 물어본다. 나머지는 기존 방식으로 진행
종류: 코드 / 크기: 보통 / 확인: 두 브라우저에서 같은 시각 표시
```
