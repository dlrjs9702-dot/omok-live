# 링크 오목 v1.3.0

회원가입 없이 방을 만들고 URL만 공유하면 실시간으로 오목을 두거나 관전할 수 있는 웹사이트입니다.

## 이번 버전 핵심

- 방 생성자가 **방장**이며 `초대하기`, `새 방`, `초대 링크 복사`는 방장에게만 표시
- 참가자는 **매 판마다** `흑 / 백 / 관전` 중 하나를 선택
- 흑·백이 모두 정해지면 자동으로 대국 시작
- 흑·백이 정해진 뒤 선택하지 않은 사람과 이후 입장자는 자동 관전
- 추가 접속자 수 제한 없이 관전 가능
- 승패/기권 후 기존 흑·백이 모두 `다음 대국 신청`하면 판을 초기화하고 **전 참가자의 역할을 다시 선택**
- 새로고침·재접속 시 같은 브라우저의 방장 여부와 현재 판 역할을 복구
- 서버가 차례, 중복 착수, 역할, 승패, 금수를 검증
- SSE 기반 실시간 동기화
- JSON 파일에 방/대국 상태 저장
- 외부 라이브러리 없음: Node.js만 있으면 실행 가능

## 오목 규칙

15×15, 흑 선공의 렌주식 금수 규칙을 적용합니다.

- 흑: 정확히 5목이면 승리
- 흑 금수: 3-3, 4-4, 6목 이상 장목
- 백: 5목 이상이면 승리, 3-3/4-4/장목 제한 없음
- 흑 4-3은 허용
- 정확한 흑 5목은 3-3/4-4 판정보다 승리를 우선하되, 장목은 금수 처리
- 금수 판정은 서버에서 수행하고 금수 착수 시 이유를 표시

※ 역할 선택형 친선 대국에 맞춰 렌주 공식 오프닝(첫 수 중앙 강제, 스왑 등)은 적용하지 않습니다.

## 실행

Node.js 20 이상이 필요합니다. 별도 `npm install`은 필요하지 않습니다.

```bash
npm test
npm start
```

브라우저에서 `http://localhost:3000` 접속 후 `새 대국 만들기`를 누르면 됩니다.

## 인터넷 배포

일반 Node.js 서버 또는 Docker를 지원하는 호스팅에 그대로 올릴 수 있습니다.
게임 데이터를 재시작 후에도 유지하려면 `DATA_DIR`가 가리키는 디렉터리를 영구 디스크/볼륨에 연결하세요.

```bash
docker build -t omok-live .
docker run --rm -p 3000:3000 -v omok-data:/data omok-live
```
